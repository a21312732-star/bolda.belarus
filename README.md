# Inkora — Smarter Marketing, Embedded AI

Одностраничный лендинг в стиле премиального AI-стартапа: розово-фиолетовый градиент, зацикленное видео с осьминогом справа (растворяется в фоне), стеклянная панель меню, появление текста при скролле и параллакс за курсором. Адаптив для телефона.

Чистые HTML/CSS/JS, без сборки — откройте `index.html`.

- `assets/octopus.mp4` — фоновое видео (autoplay, muted, loop). Замените своим файлом с тем же именем.
- `assets/octopus.jpg` — постер, показывается до загрузки видео.

Публикация: Settings → Pages → Deploy from a branch → `main` / `root`.
